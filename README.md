# 🏥 AI Agent for Hospital & Medical Shop Prescription Guidance

An AI assistant that answers medicine questions using **Retrieval-Augmented Generation (RAG)**. It searches medicines, checks stock, suggests alternatives and explains dosage, all grounded in your own medicine database and generated by a **local LLM (Mistral via Ollama)**.

```
React (Vite + Tailwind) → FastAPI → MiniLM embeddings → ChromaDB → LangChain agent → Mistral (Ollama) → Answer
```

## ✨ Features
- Semantic medicine search (meaning-based, with a light lexical re-rank)
- Stock checker, alternative suggestions, dosage guidance and FAQ
- LangChain agent with 5 tools; the LLM chooses the tool (with a heuristic fallback)
- Conversation memory, so follow-ups like "what about its dosage?" work
- Works even if Ollama is offline: answers fall back to a safe template (no hallucination)
- Chat UI: Markdown, streaming effect, auto-scroll, copy, voice input, text-to-speech, export TXT/JSON/PDF, clear chat
- Dark mode, toasts, skeleton loaders, responsive hospital-themed UI
- Caching, logging, validation, env-based configuration, Docker support

## 📋 Requirements
- Python 3.11+
- Node.js 18+ (20 recommended)
- [Ollama](https://ollama.com) with the `mistral` model (~4 GB download)
- ~8 GB RAM recommended for Mistral 7B

## 🦙 Ollama Installation
```bash
# macOS / Windows: download the installer from https://ollama.com/download
# Linux:
curl -fsSL https://ollama.com/install.sh | sh

ollama pull mistral
ollama run mistral "hello"     # quick test (Ctrl+D to exit)
```
Ollama serves on `http://localhost:11434` automatically.

## 🚀 Setup & Run

### Backend
```bash
cd backend
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
uvicorn main:app --reload --port 8000
```
On first start the embedding model downloads (~90 MB) and the CSV is indexed into ChromaDB automatically.
- API: http://localhost:8000
- Swagger docs: http://localhost:8000/docs

Rebuild the index manually any time with `python ingest.py`.

### Frontend
```bash
cd frontend
cp .env.example .env               # Windows: copy .env.example .env
npm install
npm run dev
```
Open http://localhost:5173

### Docker (everything at once)
```bash
docker compose up --build
```
Frontend → http://localhost:3000 · Backend → http://localhost:8000. The first run pulls Mistral through the `ollama-pull` job, which takes a few minutes.

### Tests
```bash
cd backend && pytest
```

## 🔌 API Documentation

| Method | Endpoint | Body | Description |
|---|---|---|---|
| GET | `/` | none | Service info |
| GET | `/health` | none | Status, medicine count, index size, Ollama availability |
| POST | `/chat` | `{"message": str, "session_id"?: str}` | Agent answer (tool routing + RAG + memory) |
| DELETE | `/chat/{session_id}` | none | Clear conversation memory |
| POST | `/search` | `{"query": str, "top_k"?: 1-10}` | Semantic medicine search |
| POST | `/stock` | `{"query": str}` | Stock status plus alternatives |
| POST | `/alternative` | `{"query": str}` | Alternative medicines |
| POST | `/dosage` | `{"query": str}` | Dosage instruction |
| POST | `/faq` | `{"question": str}` | RAG answer for general questions |
| POST | `/reload-data` | none | Re-read the CSV and rebuild the index |

## ⚙️ Configuration
All options live in `backend/.env`; see `.env.example`. Set `AGENT_ROUTING=heuristic` to skip the extra LLM call used for tool routing and make responses faster on CPU-only machines.
